# 🍵 Two Leaves Responsive Website

A modern, responsive tea brand website built using **HTML5 and CSS3**, inspired by the visual style and design of the Two Leaves Tea website.

## 🌐 Live Demo

[**View Live Website**](https://kanika01-ux.github.io/Two-Leaves-Responsive-Website/)

## ⚠️ Disclaimer

This project is a **frontend recreation inspired by the Two Leaves Tea website** and was created solely for educational, learning, and portfolio purposes.

It is **not affiliated with, endorsed by, or sponsored by Two Leaves Tea**.

All brand names, images, and visual references belong to their respective owners.

## 🚀 Features

- 📱 Fully responsive design
- 💻 Desktop, tablet, and mobile layouts
- 🎨 Modern tea-inspired UI
- 🖱️ Interactive hover effects
- ✨ Smooth CSS transitions
- 🧩 Responsive recipe card layout
- 📋 Newsletter/email input section
- 📱 Mobile navigation design
- 🖼️ Responsive images and illustrations
- 🎯 Clean and structured layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- CSS Transitions & Animations
- Remix Icon

## 📚 Learning Outcomes

- Image positioning and scaling
- Mobile-first responsive layouts

## 🔒 Security & Privacy

This is a static frontend project.

- No login system
- No user accounts
- No payment processing
- No backend
- No database
- No personal data storage
